# Поддержка колонтитулов MD2DOC Core 0.2.3

Проверены существующие правила в `src/md2doc/config/validation.py` и реализация `configure_headers()` в `src/md2doc/renderers/docx_renderer.py`. Перечисленные параметры доступны в схемах 0.1 и 0.2. Ядро и схемы не изменялись.

Пути ниже относятся к фактическому файлу стилей, указанному полем `styles` в `document.yaml`.

| Параметр | Тип и допустимые значения | Действие и визуальное управление |
|---|---|---|
| `headers_footers.header_text` | Строка | Текст обычного верхнего колонтитула; многострочное поле в группе «Верхний колонтитул». |
| `page.header_distance` | Размер: mm, cm, pt, in | Расстояние верхнего колонтитула от края страницы; числовое поле с единицами. |
| `headers_footers.footer_text` | Строка | Обычный нижний колонтитул; группа «Нижний колонтитул». |
| `page.footer_distance` | Размер: mm, cm, pt, in | Расстояние нижнего колонтитула от края страницы. |
| `headers_footers.different_first_page` | Boolean | Отдельный верхний и нижний колонтитул первой страницы. |
| `headers_footers.first_page.header_text` | Строка | Верхний колонтитул первой страницы, если включён отдельный вариант. |
| `headers_footers.first_page.footer_text` | Строка | Нижний колонтитул первой страницы. |
| `headers_footers.first_page.show_page_number` | Boolean | Показывать номер первой страницы; общая видимость нумерации также должна быть включена. |
| `headers_footers.page_number.visible` | Boolean | Включить поле PAGE в колонтитуле. |
| `headers_footers.page_number.position` | `header_left`, `header_center`, `header_right`, `footer_left`, `footer_center`, `footer_right` | Область и выравнивание номера. В интерфейсе — русские названия расположений. |
| `headers_footers.page_number.start` | Целое ≥ 1 | Начальный номер страницы. |
| `headers_footers.page_number.format` | `decimal`, `lower_roman`, `upper_roman` | Арабские цифры либо римские цифры в нижнем/верхнем регистре. |

Поля верхнего/нижнего колонтитула всегда доступны. Поля первой страницы появляются при включении отдельного варианта. Глобальные поля страницы находятся также в категории «Страница»; это одни и те же параметры, а не отдельные дублированные значения.

Текст выводится буквально и выравнивается слева. Номер страницы размещается ядром через табуляцию и поле PAGE. Колонтитулы используют стиль основного текста, с заданными ядром переопределениями абзаца. Пустая строка означает отсутствие текста. Если для первой страницы включён отдельный вариант с пустым текстом, обычный верхний колонтитул на первой странице не появится.

Отдельные шрифты/выравнивание текста колонтитула, изображения и логотипы, разные чётные/нечётные страницы, NUMPAGES и подстановки `{{metadata.*}}` для текста колонтитула текущей схемой не предусмотрены. Они не добавлялись и не имитируются. Для этих возможностей понадобились бы отдельные параметры схемы, их валидация, изменения `configure_headers()` и интеграционные проверки; такую работу следует согласовать отдельно.

Проверки на копиях EcoBuro (0.2) и doc1 (0.1) подтвердили обычный и первый верхние колонтитулы в `word/header*.xml`, поле PAGE и расстояние 12 mm (`w:header=680` twips). Проверка выполнена после редактирования Markdown и YAML и последующей штатной сборки.
